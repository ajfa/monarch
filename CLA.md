## How to sign

Add the following line to the description of your pull request, with your real
name and the date:

```
I have read the CLA in CLA.md and I agree to its terms.
Signed-off-by: Your Name <your@email> — YYYY-MM-DD
```

Also add a `Signed-off-by:` trailer to each commit, which `git commit -s` does
for you.

If you are contributing on behalf of a company and cannot agree to these terms
personally, open an issue before sending code so an arrangement can be made.
